# video-create Plugin 测试规范

## 1. 测试目标

验证最新版本 Plugin 在 Codex 真实使用环境中能否正常完成用户需求。

Plugin 的具体使用方式由 Plugin 自身的 Rule、Skill、Resource 和 Tool 定义，本规范不重复规定调用流程。

## 2. 执行规则

Plugin 完成功能调整后，测试按以下步骤执行：

1. 同步最新 Plugin 内容。
2. 在 Codex 中卸载旧版本并安装最新版本。
3. 让 Codex 宿主重新加载最新版本。
4. 用户发送一个真实业务需求。
5. Agent 按 Plugin 自身定义正常完成该需求。
6. 根据真实业务结果判断通过或失败。

安装状态、目录存在或单独接口响应只代表局部状态，不代表真实使用测试通过。

## 3. 测试边界

正常测试期间禁止：

- 使用 PowerShell、Shell、Python或 CLI 代替 Plugin。
- 直接启动 MCP Server 或发送 MCP 请求。
- 手动下载、复制或制造业务输入与产物。
- 调用底层组件绕过 Plugin 错误。
- 使用其他 Plugin 接管失败步骤。
- 擅自修改源码、配置、进程或运行环境。

只有用户明确要求排查或修复时，才进入开发诊断。

## 4. 失败处理

Plugin 在真实使用中报错时：

1. 停在原始失败位置。
2. 返回宿主收到的原始错误。
3. 列出成功、失败和未执行事项。
4. 提出可能的修复建议。
5. 等待用户决定是否排查或修复。

禁止通过任何替代路径继续完成需求。

## 5. 通过标准

同时满足以下条件才算测试通过：

- Codex 已加载本次目标版本。
- 用户提供了真实业务需求。
- Agent 通过已安装的 Plugin 正常执行。
- Plugin 产生了真实可用的业务结果。
- 全程没有使用诊断命令或替代路径。
