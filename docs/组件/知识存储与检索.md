# 知识存储与检索

## 发布边界

知识服务读取已经生成并通过哈希校验的 `reference_report_manifest.json`。预览只返回
拟发布条目；用户明确确认后才写入 SQLite。

`creation_knowledge` 只保存：

- `visibility=creation_shared`
- `transferability=reusable_mechanism`
- 来自 `creation_context_projection.json`
- 具有有效 EvidenceBundle 引用

原片专属内容使用 `reference_evidence` 隔离，不进入创作检索。

## 检索顺序

创作检索先强制过滤 `active`、阶段、knowledge type、可见性和可迁移性，再应用标签与
文本相似度排序。当前文本投影为版本化、128 维的确定性字符 n-gram 哈希向量，可随时
从 SQLite 中的知识正文重建；报告文件和 SQLite 记录仍是事实源。

精确报告读取按 `FileRef` 直接校验路径和 SHA-256，不经过文本检索投影。
