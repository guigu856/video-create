# 视频分析组件

## 职责

`components.video_analysis` 从本地视频生成可复现的技术证据：

- 使用 ffprobe 保留视频帧的原始 PTS、time base、帧序号和整数微秒时间。
- 按最大采样间隔抽取证据帧，并记录相对路径与 SHA-256。
- 生成视觉差分、候选边界和联系表。
- 对指定区间进行最大间隔不超过 100000 微秒的密集取证。

组件输出的边界统一标记为 `algorithm_candidate`。主镜头判断与语义解释由 Agent
结合证据完成，不属于本组件。

## Python 接口

```python
from components.video_analysis import AnalysisInterval, VideoAnalysisService

service = VideoAnalysisService()
result = service.analyze("source.mp4", "output/evidence")
refined = service.refine_intervals(
    "source.mp4",
    "output/refined",
    intervals=(AnalysisInterval(start_us=1_000_000, end_us=2_000_000),),
)
```

输出目录包含 `frame_index.jsonl`、`visual_signals.json`、
`boundary_candidates.json`、`frames/`、`contact_sheet.jpg` 和
`video_analysis.json`。
