# 参考报告组件

## 职责

参考报告组件消费 Agent 已完成语义判断的 `ReferenceStudyReport`，执行证据闭包、
文件哈希和逐镜时间线校验，然后确定性生成一份人类可读 DOCX、机器 JSON 与文件清单。

组件不重新执行视频或音频分析，也不补写 Agent 结论。

## 输入

- 符合 `schemas/reference-study.schema.json` 的 `ReferenceStudyReport`。
- 工作区内的报告输出目录。
- EvidenceBundle 引用的真实证据文件。

## 输出

```text
reference_study.json
reference_study_report.docx
bgm_analysis.json
reference_shot_analysis.json
creation_context_projection.json
evidence_bundle.json
reference_report_manifest.json
```

`reference_study_report.docx` 合并视频总体理解、BGM 与音画关系、逐镜分析、
可复用剪辑语法、创作阶段知识投影和证据索引，供用户在 Word 或兼容软件中阅读。
JSON 文件继续承担 Agent、知识发布和后续阶段的机器输入。

`reference_report_manifest.json` 按固定角色列出每个报告文件的工作区相对路径、
SHA-256 与 Schema 版本。当前 Manifest Schema 为 `2.0`，人类报告角色为
`human_report_docx`。知识发布读取该清单和阶段投影，不重新读取媒体进行分析。
