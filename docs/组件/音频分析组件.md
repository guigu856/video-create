# 音频分析组件

## 职责

`components.audio_analysis` 从媒体首个音轨生成确定性证据：

- 使用 ffprobe 记录原始采样率与声道数。
- 使用 FFmpeg 提取单声道 16 位 PCM。
- 生成波形、能量曲线、静音区间和瞬态候选。
- 根据瞬态间隔生成带置信度的 tempo 与 beat 候选。
- 记录 `mixed_program_audio` 或 `isolated_bgm` 音频范围。

组件只使用 `transient` 与 `silence` 等测量候选。鼓、贝斯、旋律、人声和 SFX
归属由 Agent 结合证据判断。

## Python 接口

```python
from components.audio_analysis import AudioAnalysisService

result = AudioAnalysisService().analyze(
    "source.mp4",
    "output/audio-evidence",
    audio_scope="mixed_program_audio",
)
```

输出目录包含 `audio_mono_s16le.pcm`、`waveform.json`、`waveform.svg`、
`audio_signals.json` 和 `audio_analysis.json`。
