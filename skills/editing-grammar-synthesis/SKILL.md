# 剪辑语法综合方法

以连续 `RhythmUnit`、`MainShot`、`InShotEvent` 与 `AudioVisualBinding` 为依据，把多个动作共同形成的视觉节奏归纳为 `EditingSentence`。

## 剪辑句式

一个剪辑句式说明：

- 适用的音乐段落、声音事件或能量条件；
- 主镜头切换、画中画、叠层、运动、遮挡和效果的动作次序；
- 元素提前进入、延迟退出和跨镜延续的关系；
- 镜头密度随音乐能量变化的方式；
- 快切、停留与缓冲构成的呼吸结构；
- 组合动作产生的冲击、丰富、强调、推进或叙事作用。

可用“蓄力镜头 → 连续快切 → 辅助图层叠加 → 重拍释放 → 短暂停留”一类结构描述连续机制；具体结构由当前证据决定。

## 提炼原则

- 从多个连续镜头提炼组合规律，单个镜头变化保留为句式证据。
- 区分跟随节拍、提前蓄力、拍后释放、延音维持和非节拍驱动。
- 将参考片专属人物、素材、绝对时间点、坐标和效果参数留在分析证据中。
- 以“适用条件 → 动作或组合机制 → 预期观看作用”表达可迁移机制，并保留对应分析单元和 Evidence Resource 引用。
