# 参考 BGM 分析方法

## 证据起点

先确认 `audio_scope` 表示混合节目音轨还是独立 BGM，再读取波形、能量、静音、瞬态、tempo 和 beat 候选。tempo、beat 与瞬态保持算法候选身份；声音层和段落结构由证据支持的语义判断形成。

## 独立音乐时间线

按实际声音建立连续时间线：

- `MusicSection`：识别引入、蓄力、推进、高潮、缓冲、收尾及实际存在的其他段落；
- `MusicLayer`：辨识鼓、贝斯、旋律、人声、音效及其他声音层的进入、退出与强弱变化；
- `RhythmPattern`：识别连续节拍组、重拍组合、弱拍、切分和重复节奏型；
- `AudioEvent`：标记重音、空拍、停顿、新音色、结构转折和能量释放；
- `EnergyCurve`：解释能量的上升、下降、维持、停顿和释放。

每个声音段落或事件附真实时间范围、证据引用和置信度。优先解释连续结构及其剪辑意义，单个拍点作为结构内证据使用。

## 判断原则

- 区分音乐本体、人声、环境声与后期音效对能量判断的贡献。
- 说明视觉编辑实际跟随的声音层，而非把全部变化归到基础节拍。
- 识别精确同步以外的提前蓄力、拍后释放、延音维持与留白。
- 将可观察声音事实和对段落作用的分析判断分开表达。
