# 声音和画面配合分析方法

把主要画面切换、画面内部变化、人物运动和图层变化，与重要声音变化、连续节奏、静音、强弱转折及 beat 候选对照。

## 五种配合方式

- **声音和画面同时发生**：重要声音与切换、放大或文字出现接近同一时间，用于增强力度。
- **画面提前行动**：动作先展开，在后续声音变化处完成，用于制造期待。
- **声音出现后画面再释放**：声音先到，画面随后完成变化，用于产生落地或爆发感。
- **持续声音连接前后画面**：画面已经切换，人声、旋律或音效仍在持续，用于减少割裂。
- **跟随内容而非鼓点**：画面响应歌词、情绪、音色或叙事信息，用于加强内容联系并避免机械卡点。

内部分析可继续映射到 `sync`、`anticipation`、`post_beat_release`、`sustain`、`non_beat_binding` 和 `AudioVisualBinding`，但用户报告只展示上面的中文解释。

## 判断方法

1. 写清画面发生了什么、声音发生了什么和二者实际时间差。
2. 时间接近只构成同步候选，需要结合取证精度及前后连续变化确认。
3. 说明画面响应的是重音、连续节奏、旋律、人声、音色、留白还是强弱转折。
4. 区分人物、字幕、局部图层和整个画面分别响应什么声音。
5. 将单次配合放回前后片段，判断它承担蓄力、推进、爆发、连接还是缓冲。

## 报告写法

每个重要关系使用：

```text
实际看到或听到了什么
声音和画面的先后关系
这种安排带来的效果
画面依据
声音依据
把握程度：高 / 中 / 低
```
