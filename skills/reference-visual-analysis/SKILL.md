# 参考画面分析方法

## 证据起点

读取 `frame_index`、`boundary_candidates`、联系表及候选前后证据帧。自动边界作为复核候选；真实 PTS 是镜头与事件时间边界的依据。快切、复杂叠层或作用范围含混的区间使用不大于 0.1 秒的密集取证。

## 三层观察结构

```text
RhythmUnit
└── MainShot
    └── InShotEvent
```

- `RhythmUnit`：由连续视觉动作共同形成的节奏单元，边界由视觉组织和声音结构共同支持。
- `MainShot`：主画面或叙事承载画面真实变化时建立，记录画面内容、持续关系和切换依据。
- `InShotEvent`：记录画中画、辅助图层、字幕、遮罩、裁切、缩放、位移、旋转、透明度、局部效果和整体效果等镜内变化。

主镜头时间线使用整数微秒并连续覆盖全片。镜内事件可提前进入、延迟退出或跨主镜头延续，并记录与父级主镜头的关系。

## 判断维度

- 区分主画面、辅助图层与整体合成画面，明确每个效果的作用范围。
- 记录图层主次、呼应、对比、遮挡、同时爆发及跨镜保留关系。
- 分析短暂闪现与较长停留各自承担的强调、叙事、缓冲或信息作用。
- 将观察到的画面事实与切换动机、观看作用等分析判断分开表达，并附证据引用和置信度。
