# 参考画面分析方法

## 证据起点

读取 `frame_index`、`boundary_candidates`、联系表及候选前后证据帧。自动边界只用于提示值得查看的位置；镜头和画面变化的时间以真实 PTS 和实际画面为准。快切、复杂叠层或作用范围不清的区间使用不大于 0.1 秒的密集取证。

## 观察顺序

1. 先看全片联系表，确认内容段落和画面变化密度。
2. 主要人物、主体或叙事承载内容真实改变时，记录为新的主要画面。
3. 同一主要画面中的画中画、字幕、遮罩、裁切、放大、移动、旋转、透明度和效果，记录为画面内部变化。
4. 记录变化作用于人物、局部图层、主要画面还是整个合成画面。
5. 对照前后画面，说明运动方向、遮挡、呼应、对比和跨镜保留关系。

内部分析仍可使用 `RhythmUnit → MainShot → InShotEvent` 组织数据，但这些字段不进入用户可见报告。

## 报告写法

第三章使用“完整画面时间线 + 重点片段详解”：

| 时间 | 主要画面 | 画面里的变化 | 对应声音 | 产生的作用 |
| :-- | :-- | :-- | :-- | :-- |

时间线连续覆盖全片。重点片段依次说明实际画面、处理动作、声音配合、观看作用、可以学到的方法、证据和把握程度。

## 判断纪律

- 不把每次字幕、缩放或遮罩变化误写成镜头切换。
- 将画面事实与“蓄力、强调、缓冲、连接”等作用判断分开。
- 不推测压平成片缺少证据支持的图层结构、坐标和效果参数。
- 作用解释写成观众能感受到的具体结果，不写“更高级”“更丰富”等空泛评价。
